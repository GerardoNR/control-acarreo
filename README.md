# Control de Acarreo

Sistema para el registro y control de camiones de material que se trasladan de un banco a un frente de obra, mediante captura con NFC.

## Estructura del proyecto

- `backend/` — API en NestJS + PostgreSQL
- `frontend/` — Dashboard web para el administrador (Next.js)
- `mobile/` — App móvil para los checadores (Flutter)
- `docs/` — Documentación del proyecto
